# Causality

Hardcore mobile tower-climbing game. Core hook: exceptional player achievements trigger
**causality projects** - permanent, stacking, irreversible world changes that every future
player lives with. 100 floors, permadeath, aging (3 real months = a full lifetime),
player-owned floors, player-created factions, single scarce currency ("Shards").
